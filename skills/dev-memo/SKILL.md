# Dev Memo

현재 세션(또는 사용자가 지정한 범위)의 작업 내용을 정리해서 옵시디언 Vault에 md 파일로 저장한다.

## 저장 경로

```
<OBSIDIAN_VAULT>/Development Memo/
```

설치할 때 `<OBSIDIAN_VAULT>`를 실제 Vault 경로로 바꾼다(예: `~/Obsidian/MyVault`, 클라우드 동기화 폴더 안의 Vault 등).

## 실행 순서

1. `date +%Y-%m-%d`로 오늘 날짜를 구한다. 하드코딩하지 말고 반드시 셸 명령으로 확인한다.
2. 이번 세션에서 다룬 작업 내용을 정리한다.
   - 어떤 요청이 있었고 무엇을 했는지(핵심 결정과 이유 포함, 잡담은 제외)
   - 변경된 파일 목록(있는 경우)
   - 아직 안 끝났거나 다음에 이어서 할 일
3. 파일명은 `YYYY-MM-DD-주제.md` 형식으로 정한다. 주제는 세션 내용을 보고 짧게 요약한다(예: `2026-08-13-theme-migration.md`). 같은 날 이미 파일이 있으면 덮어쓸지, 이어 붙일지, 새 파일로 만들지 사용자에게 묻는다.
4. 아래 템플릿으로 저장 경로에 Write한다.
5. 저장이 끝나면 파일 경로를 사용자에게 알린다.

## 문서 템플릿

```markdown
# {주제}

**날짜**: {YYYY-MM-DD}
**프로젝트**: {프로젝트명 또는 작업 디렉터리}

## 작업 내용
- {요청 1} → {한 일}
- {요청 2} → {한 일}

## 변경된 파일
- {file path} — {한 줄 설명}

## 결정 사항 / 참고
- {비직관적인 판단이나 이유가 있었다면}

## 다음에 할 일
- {미완료 항목}
```

## 주의사항

- 실제로 있었던 작업만 기록한다. 지어내지 않는다.
- 잡담, 메타 질문(예: "너 모델이 뭐야")은 기록하지 않는다. 실질적인 코드/설정 변경, 조사 결과, 의사결정 위주로 정리한다.
- 사용자가 명시적으로 요청했을 때만 실행한다. 세션이 끝난다고 자동으로 실행하지 않는다.
